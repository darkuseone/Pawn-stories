# Музыкальная подложка

Здесь должен лежать `bed.mp3` — фоновая музыка канала.

**Файла в репозитории намеренно нет.** В стартовом комплекте лежала подложка
сонного исторического канала: чужой трек, к этому каналу отношения не
имеющий, и его всё равно предстояло заменить. Держать чужую музыку в
репозитории, который может стать публичным, незачем.

## Что положить

Свой трек под именем `bed.mp3`. Длина любая: подложка зацикливается на весь
ролик, заход и уход сглаживаются автоматически (`render.build_audio`).

Путь задаётся полем `music` в спецификации ролика, так что файл может
называться и лежать как угодно:

```json
"music": "assets/music/auction_bed.mp3",
"bed_gain_db": -26.0
```

`bed_gain_db` — насколько подложка тише голоса. Чем меньше число, тем тише.
−26 дБ это фон, который слышно, но который не спорит с речью.

## Пока файла нет

Сборка не падает. `build.py` пишет в лог

```
! подложки нет (...) — собираю только с голосом
```

и собирает ролик с одной начиткой. Голос при этом всё равно проходит
нормализацию до −16 LUFS, так что тестовые сборки звучат так же ровно, как
готовые.
